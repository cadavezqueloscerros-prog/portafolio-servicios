# Portafolio de Servicios Web

Showcase profesional de sitios web modernos y visualmente atractivos para diferentes tipos de negocio local.

## 📋 Contenido

Este portafolio contiene ejemplos completos y funcionales de sitios web premium para:

### 1. **Clínica Veterinaria** (`ejemplo-veterinaria.html`)
- Tema: Verde y Azul (Profesional - Healthcare)
- Secciones: Servicios, Equipo Médico, Testimonios, CTA
- Características: Responsive, Animaciones, Galería de servicios

### 2. **Estética y Barbería** (`ejemplo-estetica.html`)
- Tema: Oscuro con Acentos Dorados (Lujo - Premium)
- Secciones: Servicios, Galería, Testimonios, Precios, CTA
- Características: Animaciones avanzadas, Pricing interactivo, Diseño elegante

### 3. **Restaurante** (`ejemplo-restaurante.html`)
- Tema: Marrón y Beige (Cálido - Gastronomía)
- Secciones: Menú, Galería de Platos, Horarios, Testimonios, Reservas
- Características: Menú digital, Horarios flexibles, Ambiente premium

## 🎨 Características Generales

✅ **Diseño Responsivo** - Se adapta a cualquier dispositivo (móvil, tablet, desktop)
✅ **Animaciones Modernas** - Transiciones suaves y efectos visuales profesionales
✅ **Colores Temáticos** - Cada ejemplo usa una paleta de colores apropiada para su industria
✅ **Página de Inicio** - Landing page profesional con modal preview de los ejemplos
✅ **100% HTML/CSS/JavaScript** - Sin dependencias externas, carga rápida

## 🚀 Cómo Usar

1. **Ver en Línea**: Abre `index.html` en tu navegador
2. **Vista Previa**: Haz clic en cualquier tarjeta de servicio para ver el ejemplo completo
3. **Personalizar**: Cada archivo HTML puede modificarse para adaptarlo a clientes específicos
